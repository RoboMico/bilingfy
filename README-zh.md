# Bilingfy

为语言文件设计的可视化编辑器。支持 JSON，Minecraft `.lang` 和 ResX。

采用 .NET 9 + Avalonia 框架打造。支持 Windows，Linux 和 macOS 桌面操作系统。

**本项目目前处于起步阶段**，还有很多正在进行的工作。`main` 分支目前是空的，请移步至 `dev` 分支浏览最新的进度！
