# Bilingfy

[中文](README-zh.md)

Visual editor for computer-readable language files. Supports JSON, Minecraft `.lang` and ResX.

Built with .NET 9 + Avalonia + Bunch of other cool stuff! Runs on Windows, Linux and macOS desktops.

**This is a startup project** and many things are WIP. The `main` branch is currently empty. Please head to `dev` branch to view the codes and see the latest progress!
